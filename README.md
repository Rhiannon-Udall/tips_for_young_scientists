# Tips for young scientists

This repository is a collections of tutorials, FAQs, and templates to help young scientists (especially in computation heavy roles) learn many of the core skills that aren't usually written down.
I have started this because when working with younger students, especially undergraduates, I find myself giving many of the same suggestions when it comes to *how* to do research.
So, I figured it would be good to write it down in one place, and provide other helpful resources to make sure young scientists can reach their full potential as painessly as possible!
